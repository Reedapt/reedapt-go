# Changelog

## 0.1.0

First release, with the same surface as the Node.js and Python libraries: uploads in parts (streamed from an `io.Reader`) and from links, dubs (create, retrieve, list, `ListAll`, cancel, files, transcript, subtitles, quality, `WaitUntilDone`), early-access requests, runs and lines, languages, usage and `Usage.Report`, webhook endpoints including `ResendDelivery`, webhook signature checks in the `webhook` package, retries with backoff and `Retry-After`, and idempotency keys.
